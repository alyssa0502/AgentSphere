## 总览

| 分类 | 数量 | 说明 |
|---|---|---|

**一句话结论**：AgentSphere 在**沙箱生命周期管理面**（create/connect/TTL/pause/resume/kill/timeout/lifecycle 计时器）与**命令执行面**已达到高度 E2B 兼容（近期两次平台更新还补齐了 connect TTL 只延长、lifecycle 回显、kill 即时 404 三个历史差异点）；主要差距集中在**文件系统（默认用户缺失）、公网入流（无通配 DNS）、以及 Volume/Template/快照/fork/指标等管理面端点未发布**。

## ⚠️ 可用但与 E2B 原生效果不一致（6 条）

| # | SDK 调用 | E2B 原生 | AgentSphere 实测 | 影响 |
|---|---|---|---|---|
| 1 | `Sandbox.list()` 无参 | limit 可选，默认列全量 | 后端**必填 limit**：无参 → 400 `Field validation for 'Limit' failed`；带 `limit=20` 正常返回 6 条含当前沙箱 | E2B 写法的裸 `list()` 会挂，需带 limit；E2B 官方 SDK 默认调用即踩坑 |
| 2 | `get_host(port)` | 拼 `{port}-{sandboxId}.e2b.app` 通配域，公网直达 | SDK 拼的是**默认域 e2b.app**（`E2B_SANDBOX_URL` 网关不参与域名推导）→ 实际回 301 的是 e2b.app 而非 AgentSphere | SDK 层域名推导没接到 AgentSphere 网关；叠加平台无通配 DNS（见 ❌#12），公网入流整体不可用 |
| 3 | `commands`/`files` 默认用户 | 默认 user=`user`、cwd=`/home/user` 开箱即用 | 模板无 `user` 账户：命令面报 `invalid default user`，文件面报 `unknown user user` | 不是参数不兼容而是**模板/平台缺默认用户供给**；命令面可显式传 root 绕过，文件面不可绕（见 ❌ 组） |
| 4 | `files.list('/')` | 返回根目录项（含 /home/user） | 返回**空列表而非报错**（default-user 校验被吞） | 同根因；错误形态还不同（E2B 会抛错） |
| 5 | `get_info.name` | 模板别名（如 'base'） | None | 轻微：别名体系未接入 |
| 6 | PTY `sb.pty.create(size=…)` | 会话内 write/read 回环 | 会话**能创建**（create 不报错），但本 SDK 版读法（iter/read）未取到回显，回环验证未通过 | 入口存在、可用性未证实；需按 envd Connect 协议细查读流 API |

## 横向发现：SDK 错误解析掩盖真实错误（接入面缺陷）

AgentSphere 非 2xx 响应体是华为 APIGW 风格 `{"error_code":"APIGW.0101","error_msg":"…","request_id":"…"}`，而 e2b SDK 的错误解析假设响应含 `code` 字段 → 所有未实现端点的真实 404 全部变成 `KeyError: 'code'`。这带来两个问题：
1. **排障困难**：SDK 用户看不到"API 不存在"，只看到 KeyError（与 10-16 记录的 401 掩盖是同一类问题）；
2. **错误码体系没对齐**：E2B 的错误形态是 `{code, message}`（配 `error_code` 语义串），对齐它才能让官方 SDK 用户拿到正常异常类型。

## 给 AgentSphere 的兼容性差距清单（按对 SDK 用户的杀伤力排序）

1. **P0 · 默认用户供给**：模板带 `user` 账户或 envd 支持配置默认用户——解锁文件系统全域 6 条 + 命令/文件开箱即用体验
2. **P0 · SDK 错误解析对齐**：响应体补 `code` 字段（或整体切 E2B 错误形态）
3. **P1 · 公网入流**：网关 `{port}-{sid}` 通配 DNS + SDK get_host 域名推导接入网关域——解锁浏览器/回调类场景
4. **P1 · `Sandbox.list` 兼容无参调用**（limit 给默认值）
5. **P1 · auto_resume 真实生效**（流量触发恢复）
6. **P2 · 管理面补端点**：Volume、Template 元数据/tags/alias、显式 snapshot、fork、metrics、logs、presigned 文件直传、update_network
7. **P2 · Secret 域**：确认平台是否实现；SDK 包补 Secret CRUD 入口
