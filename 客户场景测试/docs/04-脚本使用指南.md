# 04 · 脚本使用指南

## 0. 环境变量（所有脚本共用）

| 变量 | 说明 |
|---|---|
| `E2B_API_URL` | AgentSphere 控制面 API 地址（控制台获取） |
| `E2B_SANDBOX_URL` | 沙箱数据面网关地址（控制台获取） |
| `E2B_API_KEY` | 访问 key（控制台获取；**勿写进代码/仓库**） |
| `SWR_USER` / `SWR_PASS` | 仅镜像推送脚本需要；SWR 临时登录凭据，24h 有效 |
| `TPL` / `RD_FILE` / `RD_N` | 读测脚本的模板 ID / 目标文件 / 台数（可选覆盖） |

Windows 一次性注入：`setx E2B_API_URL "..."` 等，重开终端生效。
Python 依赖：`pip install e2b`（推送脚本另需 `requests`，沙箱内自带）。

## 1. read_bench.py —— 大文件读对照·交互版（主交付）

- **输入**（运行后逐项提示，回车取默认）：模板 ID、沙箱台数、目标文件路径
- **流程**：顺序 N 台，每台 create→envd→UI+浏览器就绪→`cat` 首读/二读/三读；**测试期间不销毁**，全部测完统一 kill
- **输出**：每台明细（create/envd/就绪/首读 MB/s/二读三读/端到端/层判读）+ 汇总（三档分布、min/p50/max），落盘 `readbench_<时间戳>.txt` + `.csv`
- **兜底**：异常或 Ctrl+C 时自动销毁已创建沙箱
- 判读口径（500MB）：>20s 真冷读 / 2-20s 盘读 / <2s 页缓存

## 2. chromium_read_ab.py —— 单文件快速对照（环境变量传参）

```bash
TPL=<模板ID> RD_FILE=/opt/bigfile-500mb.bin python chromium_read_ab.py 2
```

- 严格顺序（第 1 台含读完文件全完成后才拉第 2 台），**逐台测完即销毁**
- 适合快速验证单个模板；毫秒打点在沙箱内，端到端在客户端

## 3. bigfile_bench50.py —— 批量分布测试

```bash
TPL=<模板ID> RD_FILE=/opt/bigfile-500mb.bin python bigfile_bench50.py 50
```

- 与 read_bench 同流程但默认 50 台；看分布收敛（真冷读/慢径残留/快径占比）
- 50 台同时存活约 4-8 分钟；输出 `bench50_<时间戳>.txt`

## 4. spawn_bench.py —— 拉起耗时基准（不含读文件）

- 交互输入：模板 ID、台数、测完是否销毁
- 测 create API / envd 可执行 / UI 3001 / chromium 9222 / 端到端 + 冷热判定
- 严格上一个沙箱完全就绪才创建下一个；失败即停
- 模板若无 chromium（9222 不通），自动降级为只测 UI

## 5. img_push3.py + img_pusher_inner.py —— 镜像制作推送

```bash
IMG_TAG=20261105c SWR_USER=... SWR_PASS=... python img_push3.py
```

- 编排脚本在本地跑：拉源模板沙箱 → base64 注入 inner 脚本与凭据 → 沙箱内 dd 500MB → 触发 rootfs 导出直推 SWR（约 4 分钟）
- `img_pusher_inner.py` 必须与编排脚本同目录（会被上传进沙箱执行）
- 详见 [03-镜像制作与推送](03-镜像制作与推送.md)
